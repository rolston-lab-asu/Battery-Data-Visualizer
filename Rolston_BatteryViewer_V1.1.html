EIS datasets
Window: sweeps 1–1
D = diffusion-limited (~45° Warburg branch at low frequency, solid lines); K = kinetic/charge-transfer only (the arc closes, dotted lines). Which regime a sweep can even observe is set by the lowest frequency it reached, so D and K are usually two different measurements rather than two cell behaviours — showing them separately avoids comparing a 9 mHz sweep against a 1 Hz one. Colour = cycle age (see colour-bar).

Features (columns)
One worksheet per battery file, named after the file. Every row is exported — the graph view, Rows filter and EIS dataset selection do not affect it. If an impedance column (freq/Hz, Re(Z)/Ohm, …) is selected, non-EIS rows are automatically skipped since BioLogic zero-fills them there (no real value to export).

Column Glossary

How the data is recorded. Rows are logged on events, not on a fixed clock — a new row is written whenever a set time passes, or voltage / current / charge moves by a set amount. Stable plateaus produce few rows; fast changes produce many. Every row is tagged with a cycle number (one charge + one discharge = one cycle) and an Ns protocol-step index. Impedance (EIS) rows carry freq/Hz > 0; DC cycling rows have freq/Hz = 0, so most impedance columns read 0 on cycling rows.
